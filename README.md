# 懶人計畫表｜Lazy Student Planner

一套從高中生實際讀書需求出發設計的學習規劃網頁，嘗試將每日任務、重要事項與長期學習目標集中管理，而不只是建立待辦清單。

**作品展示：** https://chouirisbaby-byte.github.io/-/

## 開發動機

準備學測時，我發現一般行事曆雖然方便記錄日期，卻不容易同時掌握每天要做的事、跨週的進度，以及需要分階段完成的長期目標。因此，我開始設計一套符合自己讀書習慣的網頁，讓計畫不只是寫下來，也能隨著實際完成情形持續調整。

## 核心功能

### 1. 三種檢視模式

- **週檢視：** 以七天為單位瀏覽當日任務與重大事項，快速掌握一週安排。
- **月檢視：** 從月曆查看任務、重大事件與讀書時數等資訊，方便掌握較長時間的安排。
- **計畫規劃：** 設定長期計畫的起訖日期與進度，並將較大的目標拆分為階段任務。

### 2. 每日任務與重大事項

- 新增、修改、完成及刪除每日任務。
- 以 A／B／C 等類別區分任務，協助辨識不同性質的學習工作。
- 記錄考試、活動等重大事項，並以顏色輔助辨識。

### 3. 長期目標與進度管理

- 建立具有時間範圍的長期計畫。
- 透過進度條與階段任務，追蹤目標完成情形。
- 依照實際使用情況持續調整計畫與介面設計。

## 技術與設計

- **HTML：** 建立頁面結構與表單。
- **CSS：** 設計響應式介面及行動裝置版面。
- **JavaScript：** 管理任務資料、日期切換、進度顯示與操作互動。
- **瀏覽器端資料保存：** 部分版本使用 `localStorage` 保存資料；實際儲存及同步機制請以目前部署版本為準。

此專案的重點在於將「日常紀錄」與「長期進度」整合成方便使用的介面，並在使用過程中反覆調整功能需求及資料之間的關係。

## 操作方式

1. 開啟上方作品展示連結。
2. 在「週檢視／月檢視／計畫規劃」之間切換。
3. 選取日期，新增或管理當日任務及重大事項。
4. 進入計畫規劃頁面，建立長期目標並追蹤完成進度。

## 開發歷程與後續方向

開發過程中，我曾針對重複性練習、階段任務的完成判定、逾期提醒及資料匯出等需求反覆規劃與調整。這些功能在不同版本中的完成情況不一，因此沒有全部列為目前版本已驗證的功能。

後續希望持續改善：

- **重複性計畫：** 依目標回數與截止日期追蹤完成量。
- **階段任務：** 讓階段進度與每日完成情形更一致。
- **逾期提醒：** 清楚標示超過期限且尚未完成的任務。
- **資料匯出：** 將計畫整理成便於保存的 PDF 或 Word 檔。
- **資料可靠性：** 進一步確認不同裝置及同步情境下的資料保存方式。

## 專案說明

這是以個人使用需求為起點、持續修改的學習工具。開發過程曾使用生成式 AI 協助程式撰寫與除錯；我主要投入需求整理、功能規劃、介面調整與實際使用測試。本專案仍有待完善之處，不以商用或完整成熟產品自居。
